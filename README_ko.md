AWS 기초, 스토리지와 권한에서 시작해 네트워크, 컴퓨팅과 데이터베이스를 배웁니다. Web 및 Serverless 프로젝트로 지식을 연결하고 보안, 모니터링, 메시징, 워크플로와 자동 배포로 확장합니다. 필요에 따라 DNS/CDN, 컨테이너, 공유 스토리지, 캐시, 분석과 AI를 탐색합니다. 가이드 실습 뒤 독립 챌린지에 도전하며 진단과 리소스 정리를 연습합니다. 선택한 시험 가이드와 함께 이 실습을 AWS 자격시험 준비에 활용할 수 있습니다.
